# Xai-AC

## Setup

Add the paper plugin or fabric mod to the server. Start it, then adjust config\\xaiacserver.json to your likings. Some mods come with bundled mods (e.g. cloth-basic-math) that get flagged if not added.



I recommend using whitelist mode with hash checks. This will force players to only use exactly your mods. Use the config generator mod to automatically generate a whitelist config file.



Client-Side Anticheats are NOT perfect. XaiAC uses encryption to make it far more secure than similar mods, but i still recommend it to be used with a server-side anticheat.
